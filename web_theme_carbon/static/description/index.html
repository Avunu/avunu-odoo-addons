Carbon Backend Theme

IBM Carbon Design System styling for the Odoo backend

Restyles the Odoo web client to match IBM's Carbon Design System: the IBM Plex type scale, Carbon's blue-60 interactive colour, the neutral gray ramp, square corners and Carbon's 2px inset focus ring.

Light mode uses Carbon g10; dark mode uses g100 and follows Odoo's own colour-scheme switch, so the existing dark-mode toggle just works.

The theme is CSS only — it overrides no QWeb template and patches no OWL component, which is what keeps it portable across Odoo versions.
